# Assignment 5 — JavaScript Basics

## Description
This is my Front-End Development Assignment #5. The project demonstrates basic JavaScript, DOM manipulation, and event handling using HTML, CSS, and JavaScript.

## Tasks
- **Task 0 — First Script:** Display a message with `alert()` and print student information using `console.log()`.
- **Task 1 — Variables & Operators:** Use strings, numbers, booleans, arithmetic operations, and string concatenation.
- **Task 2 — Changing Content:** Change paragraph text when a button is clicked.
- **Task 3 — Changing Styles:** Change a block's background color and font size.
- **Task 4 — Creating & Removing Elements:** Add and remove list items.
- **Task 5 — Mouse Events:** Change a box's color on mouseover and restore it on mouseout.
- **Task 6 — Keyboard Events:** Show input text using the keyup event.
- **Task 7 — Calculator:** Perform addition, subtraction, multiplication, and division.
- **Task 8 — To-Do List:** Add, mark, and delete tasks using a JavaScript array.
